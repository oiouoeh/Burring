    Formula reference

    Pierce hole diameter, from neutral-line length constancy (Romanovsky form with H = h + t):
    d = D1 − 2h + 0.86·r + 0.43·t

    Height from a given hole:
    h = (D1 − d)/2 + 0.43·r + 0.215·t

    Required hole expansion ratio:
    λ_req = (D_basis − d) / d × 100 %   D_basis = D1 or D1 + t

    Flanging coefficient: K = d / D1 (smaller K = more severe)

    Edge thickness after forming: t1 ≈ t · √(d / D1)

    Maximum height at the allowable limit:
    d_min = D_basis / (1 + λ_allow/100)   h_max = (D1 − d_min)/2 + 0.43·r + 0.215·t

    Root bend strain (outer fibre): ε ≈ 1 / (2r/t + 1)   compared with the material's minimum bend R/t. Default die corner radius is r = 0.5·t (field standard); a smaller r lengthens the straight wall but raises λ_req and root strain.

    Minimum land width: f_min = t + r + k·t (k = 1.5 to 2.0 typical)

    Reference die opening: D_die ≈ D1 + 2t

    The length method ignores wall thinning, so actual height usually comes out slightly higher than calculated. Use the result as a starting value and correct the pierce hole after try-out. HER values in the material list are typical figures for punched holes; replace them with mill data (ISO 16630) when available.
